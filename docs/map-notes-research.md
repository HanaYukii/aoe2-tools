# 地圖注意：內容與來源

複核日期：2026-11-13。收錄 28 張歷來地圖，適用一般隨機地圖的 1v1 與團戰；不代表本週圖池。這輪改寫 27 張，超級隨機依先前要求保留。

## 編輯原則

每張以 2–4 個短項目說明開局差異與重要決策。刪除固定的團戰口號、一般偵查常識與沒有用途的村數。數字只保留特殊起始、建築成本，以及有目的的操作範圍。阿拉伯與競技場只留入口提醒，詳細配工仍看文明／防守速查。

- 原始機制：本機官方 RMS、遊戲語系與官方更新。
- 資源樣本：AoE Buddy 的各圖 `details` 頁；樣本通常只有數十場，使用「通常／常見」，不把平均量、TC 直線距離或整圖數量寫成每場固定值。
- 打法：Sitaux 各圖原始教學的公開可讀內容，加上整理者的情境判斷。不將單 TC、快帝或特定採石量寫成通用最優解。
- 玩家既有用語保留裝甲、肉馬、矛、BK、TC；Fortress 的選單標題依遊戲繁中改為「要塞」，「堡壘」仍是別名。

## 開局與成本核對

| 項目 | 核對結果與編輯用途 |
|---|---|
| 乾草原 | 官方 `steppe.rms2` 啟用 NOMAD_MAP、ADDITIONAL_VILLAGERS 3 與帳篷物件。一般文明六村先蓋 TC；不固定帳篷數與上限。 |
| 斯堪地那維亞 | 官方 `Scandanavia.rms` 設 LUREABLE_GROUPS 3、HUNTABLE_COUNT 4、HUNTABLE_SMALL_COUNT 8。提醒第三隻大型獵物、羊留作銜接，未把原始物件總數換算成固定可採食物。 |
| 林間空地 | 官方 `Glade.rms` 主金、主石各 4 格；[RP 樣本](https://aoebuddy.com/maps/glade/details)交叉確認。家金約 3,200，因此上城要規劃出口外的資源。 |
| 與世隔絕 | [RP 樣本](https://aoebuddy.com/maps/enclosed/details)為家金 7 格、家石 2 格，石頭約 700；結合不可建造的岩路，帶出外礦落點與第二堡的石源。 |
| 要塞 | 官方 `Fortress.rms` 一般 RM 額外 7 村，連同標準 3 村為 10 村，另有城堡與 5 田；區分 Regicide、Empire Wars 與其他起始設定。現成城堡能滿足升帝的建築條件，不能取代上城的兩座封建建築。 |
| 港與魚 | 一般港 150 木、漁船 75 木，所以港＋3 魚為 375 木，不含房子、軍費；暫停新魚只省木。 |
| 直城建築 | 市場 175 木＋兵工廠 150 木＝325 木，非漁業上城的額外固定必做路線。 |
| 遷徙 | 運輸 125 木＋TC 275 木、100 石，合計 400 木、100 石。4–6 登陸村是施工起點，並非經驗證的最佳配工。 |

成本不含文明折扣。一般開港第 11–13 村、黑暗 3–4 魚與單港約 5–6 木村，沿用既有 [SilverHawk 四湖流程](https://aoecompanion.com/b/lf4vyc4qi8)的保守練習節點；該流程是舊文明版本，只取開港分工，不搬用上時代人口與舊魚速。立陶宛極早港另有專門流程。採石 3–4 村、移採 4–6 村等為整理者提供的操作範圍。

## 海戰版本

- [官方 169123：海戰改版](https://www.ageofempires.com/news/age-of-empires-ii-definitive-edition-update-169123/)：漁船可進駐港；中型戰艦一起升級箭船、火船、躉船主線。未沿用舊版「只有噴火船」的反制描述。
- [官方海戰介紹](https://www.ageofempires.com/news/a-new-naval-warfare-in-age-of-empires-ii-definitive-edition/)：一般港有 5 格進駐；躉船對火船、箭船對躉船的定位。
- [官方 177723](https://www.ageofempires.com/news/age-of-empires-ii-definitive-edition-update-177723/)：碼頭最大箭數改成黑暗／封建／城堡／帝王 0／3／4／5。卡片寫黑暗不射箭、封建最多 3 箭，不把進駐容量當箭數。
- [官方 188329](https://www.ageofempires.com/news/age-of-empires-ii-definitive-edition-update-188329/)：核對目前版本；小雞／兔類不再能藉 funneling 長距離帶回。小雞地形保留早留磨坊木的提醒。
- 遊戲英文 Hulk 對應繁中「躉船」，以本機英文／繁中相同字串 ID 核對，沒有另造「重型帆船」名稱。

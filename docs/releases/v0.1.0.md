# v0.1.0 — 首個 Windows 分享版

下載下方 **aoe2-opponent-dashboard.exe**，雙擊即可使用，不需安裝 Python。

- 首次設定：自動尋找 Steam 遊戲、錄影位置，選擇自己的玩家。
- 深色對局筆記、最近 10 場、文明詳情與特殊兵種應對。
- 可選擇關閉官方排行榜積分查詢；設定只保存在本機。
- 自製圖示、單一 Windows x64 EXE，附 SHA-256 校驗檔。

需要本機安裝 Age of Empires II: Definitive Edition；目前以 Windows Steam 版測試。EXE 未做程式碼簽章。

首次使用步驟與範例截圖：[README](https://github.com/HanaYukii/aoe2-tools#readme)。

# 勃根地競技場：被壓堡後，怎麼守到帝王

先練一條主線：**內牆＋2 TC → 第一座防守堡＋少量守軍 → 存帝 → 巨投／火炮反推**。

這是單挑競技場的練習參考，假設已到城堡、仍有安全資源可採。隊友支援、多家合推或資源全被封時，需要另外判斷。文中的兵量、55–65 村及配工是方便練習的建議，並非職業選手固定流程或保證守得住的門檻。P 指人口；採集分配與停村判斷用村數。

## 1. 第一個判斷：這座堡到底封到什麼？

不要只看「他蓋好了」。先看三件事：

- 安全木區與金礦還剩哪裡？石礦是否仍可採？
- 堡下只有少量兵，還是已接 BK、衝車、投石與第二批工人？
- 對手要從原本城門進來，還是能從側邊打開新入口？

「資源被封」是指村民會被城堡或守軍射到，或往返必經敵軍控制的路，不是整種資源一定完全不能採。先做以下調整：

| 被封的資源 | 馬上做什麼 | 家裡沒有安全替代點時 |
| --- | --- | --- |
| 前方木區 | 撤到後方木線，補伐木場；別讓村隔著半個家來回走 | 內牆先保另一側木線；需要出門找木時先探路、補掩護，別盲派整群村 |
| 主金 | 換家中副金，補採礦場 | 市場買少量金救急，先保第一批守軍；要重新取得金礦才談持續出兵與存帝 |
| 石礦 | 換安全石礦採第一堡 | 先靠牆與守軍撐，接近 650 可視庫存買最後缺口；不能仍假設 8–10 村一直有石可採 |

撤回來的村先轉安全資源，避免原地閒置。沒有安全木金時，「先守」具體是先支付內牆、營地與第一批能守入口的兵，暫緩額外 TC；目的是保住或重新打開採集空間，不是單純龜著等資源增加。

堡沒壓住資源、進攻兵也少，可以用短牆與少量兵擋住，繼續經濟。堡已封金、石或即將切斷木區，就要提前搬家、補守軍，不能只等存帝。地基剛下且手上有足夠兵才考慮攔工人；不要拉一整片村民去賭快完工的堡。

## 2. 拉牆與 TC：縮到能守的範圍

第三 TC 還沒下，先暫停，預設以兩 TC 維持經濟。已經三 TC 不必拆，資源緊時暫停其中一座。只有一 TC 且正在破防，也不必為了湊兩 TC 再花一筆木石。

內牆接房屋、兵工廠、市場等建築，縮短要守的邊界。要保的是能持續採集的木金、田與通道，不是原本整圈基地。牆與採集點退到敵堡火力外，還要考慮對手後續升射程；別把內牆貼著外牆蓋，讓一次突破就直達田區。

拉牆先派 2–3 村，沿「安全樹林／已完成建築 → 短牆 → 房屋或另一片安全樹林」接成封閉邊界。先封最短的缺口，不要同時拉一整圈長牆。接點要補實，特別是斜角、房屋旁與樹林被砍穿的位置。房屋血量不足或快倒時，要能在後面再補一小段。

內外牆中間留出能反應、補牆與讓守軍轉向的空間；沒有通用的固定格數，敵堡射程與地形優先。敵人還沒接近可先用木牆封小洞，主要承壓入口再改石牆；敵兵已在打就不能把薄木牆當長期防線。石牆也要有投石或守軍掩護，不是蓋好就不看。門只放在需要通行的地方，不用就鎖住，自己要出門時再解鎖。

BK 與修道院放內線，別拿尚未出第一隻兵的建築當最前面唯一一段牆。修牆村要有安全站位，守軍能在兩個入口間移動。門別因自己單位通過而讓敵軍跟進。看到炸藥桶、側邊新地基或砍木形成缺口，立即調整防線；一條牆不是永久安全保證。

## 3. 第一堡快挖；第二堡慢慢準備

需要防守堡時，先用 **8–10 村採石**當練習起點。550 石只算城堡缺口，還要加上石牆與修理預留：

**尚需採石＝650（城堡）＋還沒付的牆費＋預留修理石－目前石頭庫存。**

例如起始 200 石，第二 TC 花 100，剩 100；接著拉 10–20 格石牆（每格 5 石，另需 50–100 石），再留 50–100 石作初始修理預算，總共約需再採 **650–750 石**。這個預留不是保證修得住整場；若已經付過牆費，就用當下庫存計算，不重複加一次。石門等其他花費另計。

**實際庫存到 650、能安全施工就先下堡，不必等修理預留也採滿。** 工人施工時礦上的村繼續採，完工且預留夠了，再把大部分石村轉走。

近礦、有採礦場、不中斷採集也仍需要數分鐘，不能期待看到敵堡才挖石就立刻反蓋。先靠內牆與守軍爭取施工時間；石礦已被封，就換安全礦或調整守法，別派村在火力下硬採。

第一堡位置依序看：

1. 工人能否安全走到並完成施工？
2. 能否罩住破口、木金與退路？
3. 如果對手先帝王、架起巨投，村民能否撤往另一塊資源？

約 6–8 村安全施工即可作為起點，急迫時再增加；不把「在敵堡射程內派更多村搶蓋」當預設。

**第一堡完成、初始修理預留足夠後，只留 2–3 村慢採石**，其他採石村轉回食物、木金。保留一些石頭修堡，不是湊到 650 就一定立刻花掉。第二堡若需要，放側後方保新木金、TC 與退路；不是一味往最深處塞，也不是兩堡擠在同一條巨投火線上。不要為第二堡延後點帝。若第一堡已經修不住，別把石頭與村民全投入必倒的位置。

## 4. 守軍怎麼補：一批一批檢查

### BK、修道院什麼時候下？

預設不是到城就無條件兩棟一起蓋，而是**看到第一波要處理的威脅，就先下能解它的那一棟**。不要等牆倒才開始蓋。

- **遠程兵開始壓牆，或看到敵方投石往前走：先 BK。** 若確認城堡後會接這波進攻，也可提早下。BK 200 木＋第一台投石 160 木／135 金，至少要把 **360 木＋135 金**視為一筆需求，別蓋完 BK 卻沒錢出車。直城通常已有兵工廠；沒有的話要先補前置兵工廠。
- **騎士、征服者等可直接招降的高價兵先來：先修道院。** 修道院 175 木＋第一隻和尚 100 金。已有搶聖物用修道院，就把下一隻和尚留家，不再蓋第二棟。若是攻城器類單位，不能直接套用這條招降預設。
- **兩種威脅都有：先補最迫切的一棟與第一隻兵，再接另一棟。** 兩棟＋一投石＋一和尚合計 535 木／235 金，還沒算房屋、牆與田，不能忽略這個木頭缺口。
- **只有一座空堡，資源仍安全、沒有兵壓牆：可先內牆與防守堡，暫緩 BK。** 持續看外牆與側路；如果連內牆都沒時間補好，或已看到破口兵，就不是這個情況。

修道院不設固定幾村才蓋；這條防守線以敵兵為觸發，可能比和平搶聖物流程更早。採石、拉牆與下軍事建築可以同時進行；若不夠資源，守住即將破的入口優先於照表補 TC。

不要把下表全部加起來生產；先選對面真正投入的那一列。

| 眼前威脅 | 練習起手 | 何時繼續加 |
| --- | --- | --- |
| 一般遠程兵壓牆 | 1 投石，利用牆與堡掩護 | 兵持續增加、同時威脅兩處時補第 2 台；分開站位互相掩護 |
| 騎士、可直接招降的高價單位 | 1–2 和尚 | 持續出馬可補到 2–3 和尚＋4–6 槍兵；反覆交戰再升長槍並續補 |
| 肉馬抓和尚、繞後排 | 槍兵守住和尚與投石 | 依馬量補，別讓槍兵追出保護範圍 |
| 日本武士等近戰步兵 | 堡、內牆與 1–2 投石 | 投石壓不住時考慮弩兵；不要拿槍兵當反步兵主力 |
| 衝車抵牆 | 準備近戰拆車 | 無護衛才拉村拆；已有馬廄且能打贏護衛，可少量騎士處理，不必為一台裸車立刻開完整馬線 |

高傷害遠程兵可能很快點掉投石，不能把「投石剋遠程」理解成可以硬對射。和尚也不是能直接招所有攻城器：一般攻城器需要救贖等條件，衝車還有特殊限制；初學這頁先按近戰拆車準備。

1 投石＋1–2 和尚只是低投入的檢查點，不是完整防守保證。要出第 3 台投石或持續補大批兵時，代表正在打城堡時代戰，接受點帝延後比把資源存著等破防好。

## 5. 守穩後怎麼農、何時停村？

**約 50 村開始檢查是否能存帝；約 55–65 村且防線穩定時，可開始暫停一座 TC。** 不用套用和平局「約 95P 點帝」。已經有資源就更早點，不用等滿指定村數；守不住也不要為了達成數字硬停經濟。

60 村可以先抓：**32 食／14 木／12 金／2 石**。這是分配起點，不是每局照表搬人。食物村以安全田為主；木不夠補田、修牆、出投石就先加木，缺點帝金就調金。留下的兩村石是慢慢備修理與第二堡。

一座 TC 持續出村約消耗 120 食／遊戲分鐘，兩座約 240 食。暫停一座，可以開始累積食物；接近點帝再短停另一座。村民要繼續工作，避免排隊或閒置的資源耽誤防守。停村是短期取捨，不是永久停在 60 村。

存帝前檢查：

- 現有牆、堡與守軍，能撐過升級期間嗎？
- 木金採集還安全嗎？對方是否又補 BK、第二堡或破口兵？
- 1000 食＋800 金是否可在短期湊齊？非必要科技與額外建築能否先緩？

### 經濟科技點到哪裡？

用「一木、一農已完成，二木優先，二農看撒田，輪軸守穩補」當這條線的起點。你原本直城已點好二木、二農就繼續利用，不需要改掉已完成的開局。下面是受壓時的取捨，並非要求一到指定村數就點。

| 科技 | 這條防守線的建議 |
| --- | --- |
| 一木、一農 | 當作基本盤；漏一木有餘裕就補，一農盡量趕在下一批撒田前完成。但牆快破、缺首隻守軍時先救防線。 |
| 二木 | 最優先補的進階經濟科技；牆、田、BK、投石都缺木。勃根地費用 90 食＋100 木，先留好首台投石／和尚與建築費再點。 |
| 二農 | 75 食＋125 木；還要撒一批安全田時補。已種下的田不會回補科技新增的食物量，不要為它延誤當下急需的守軍。 |
| 輪軸 | 105 食＋50 木，30 多村、雙 TC 運作且首批防守到位後補；其他 TC 繼續出村。研究占 TC 75 秒，正在危急存帝時別為村數門檻硬插。 |
| 手推車 | 180 食＋200 木，約 50–60 村且還要農一段時間、前線穩才補。已要停村存帝就先緩，升帝途中可在另一座 TC 補，但不能吃掉化學與首批軍費。 |
| 一級金 | 60 食＋75 木；約 8–12 村會持續採金，且第一批守軍已到位時補。只差一點金就能點帝，先點帝。 |
| 一級石 | 60 食＋75 木；只急採第一堡、之後降到 2–3 村，本頁預設先跳過。若要長期 8–10 村採石、修堡或補第二堡，再考慮；不要為研究等第一堡。 |
| 三級木農、二級金石 | 這條受壓存帝線先緩；反推站穩或轉回長期發展再補。 |

勃根地現版經濟科技是**食物費減 40%，木頭不打折**，所以便宜不代表不占用 BK、投石與撒田的木頭。上述費用依目前科技樹資料核對；科技先後與村數是本頁的練習建議。市場可補最後缺口，但別預設賣光還要修堡的石頭。

## 6. 升帝與到帝：別只存出升級費

升帝途中，在安全位置補學院；前面已蓋 BK 就沿用，還沒蓋才補一座，走火槍再補射箭場。這是受壓反推，不用立刻照後期配置蓋滿 4 射箭場、3 馬廄、2 BK。先確保第一批兵能出來，再擴產。

到帝馬上點化學；**已有城堡可先出一台巨投，不用等化學完成才開始反擊**。巨投要 200 木＋200 金；化學需 300 食＋200 金，還要研究時間，不能把到帝視為立刻有火炮。後續再存首批火炮與護衛費用。

第一台巨投不要被銀冠、徵兵等城堡工作卡住。反推順序通常是保住己方攻城器、處理對方威脅最大的攻城器，再拆前堡。有前排才接 1–2 火炮；對步兵補火槍，對馬補戟兵，對應攻防別忘。你先前用火炮＋火槍打回日本武士，就是可以練的方向，但對方轉遠程或出馬仍要改護衛。

對手先帝王，先看第一台巨投多久會到、自己的堡能修多久。能爭取時間才修，準備撤村與搬資源，不要為保住第一堡送掉全經濟。第二堡的位置價值就在保留新的防線，而不是保證第一堡永遠不倒。

升帝中的另一座 TC 視軍費恢復出村，升級完成後再恢復主 TC。站穩後補 TC、產兵建築、徵兵與銀冠；**記得蓋房子**。

## 7. 分三次練，不用一次記完

1. 第一階段只練內牆、搬資源、第一堡位置；記錄哪個入口失守。
2. 第二階段練少量守軍：每補一批前先看敵方兵種、數量與增援，而不是所有兵種一起出。
3. 第三階段才練 50 村開始檢查、短停 TC 存帝，以及到帝第一台巨投接化學。

復盤看五件事：多蓋的 TC 有沒有拖住防守？第一堡後是否還留太多村挖石？投石／和尚是否死在護衛不足？存帝時是否已經斷木金？到帝後是否缺木金或被城堡科技卡住第一台巨投？

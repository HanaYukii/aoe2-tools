# 羅馬：衝車打一波，打不進去就蓋堡跟帝

主線是 **長劍＋衝車先打出壓力，順帶接第二 TC；對方組合不好打，就保住原兵，步兵＋弩砲守位置、加速採石蓋堡，再跟帝王**。這是一套操作提醒，村數不是硬性門檻，遇到威脅要提早應對。

## 關鍵節點與配工

木、金、石先按需求分，其餘食物；不要把每個區間的上限全部加在一起。施工村、修理村都從現有配工抽調，不另外算一批村。

| 階段 | 大概村數 | 主要操作與分配 |
| --- | --- | --- |
| 點城到抵達城堡 | 38–45 | 12–16 木、5–7 金，其餘食；到城抽 1–2 木村下 BK，先付長劍與二級步防 |
| 首波推進、接第二 TC | 42–55 | 14–18 木、6–8 金，其餘食；留 275 木＋100 石，抽 4–6 木村蓋安全 TC |
| 首波不適合繼續打 | 45–65 | 停加衝車，弓兵多先補 2–3 弩砲；原兵退到能保住的位置，不必等指定村數 |
| 加速採石蓋堡 | 45–65 | 16–20 木、8–10 金、6–8 石，其餘食；60 村例：26 食／18 木／9 金／7 石。石夠抽 6–8 村安全施工 |
| 堡站穩、存帝 | 65–85 | 降至 2–3 石，16–20 木、12–16 金，其餘食；75 村例：40 食／18 木／14 金／3 石 |
| 升帝、反推 | 按升帝進度 | 抽 1–2 木村補需要的產兵建築，留巨投與主力升級費；到帝抽 2–3 木村跟後排修理 |

## 什麼時候停止追加衝車？

先抓 8–12 長劍＋1–2 衝車，打得贏護衛才拆建築。看到下列情況，就先保兵、不要照原計畫一直補車：

- 投石車已到，能持續打到你的衝車或密集步兵。
- 對手護衛兵種剋你的長劍，清不掉就沒有安全拆建築的機會。
- 城堡或狹窄通道堵住，衝進去會持續掉兵，卻拿不到木金或重要建築。

打不進去不等於立即放棄所有前線：可退到安全路口、對方資源外圍，讓原兵保住控制範圍。但回家路與己方木金要守得住，別把兵丟在敵堡下。

## 步兵＋弩砲是守位置的主體，不是解所有兵種

弓兵／馬弓多，先 2–3 弩砲，有餘裕再到 4–6 台，步兵在前，守木金與路口。不要追著馬弓跑，也不用因為轉運營就把所有長劍換掉。

**對方投石車仍在時，不能只靠多造弩砲解決。** 弩砲分散、退離射程，視需要補己方投石對轟；有安全側路才讓近戰貼上。對方有護衛、碰不到投石就退守自己的堡位，延後額外弩砲。已有馬廄可以少量騎士切投石，但不預設為這件事再開整條騎兵線。

騎士壓來，先 1–2 和尚；騎兵持續增援，就補 4–6 槍兵起手、升長槍並續補。遇到反步兵單位，減少長劍的追加量、改補適合的遠程。已有矛兵也可先升精銳，不必同時把矛兵與弩砲兩套科技都升滿。

## 為什麼改成 6–8 村採石？

原本「3 村慢採」是預留以後的城堡，現在你的目的變成及時建立堡位、保住弩砲與經濟，因此轉運營時提高到 6–8 村。若起始石沒有賣、第二 TC 花 100，還有 100 石，蓋堡至少還差 550；牆與修理預留另算。

這段會壓縮食物收入，缺資源時先減少額外軍隊、暫緩第三 TC；防線正在崩就先補兵，不能只顧湊石。堡好後降至 2–3 村採石，其餘回田與金，避免第一堡蓋完仍有八村長期挖石、反而沒食物上帝。

城堡優先保安全木金、弩砲撤退路與能架巨投的位置。不要為了前壓多幾格，讓施工村被對方投石與軍隊吃掉。

## 跟帝的投資順序

先保現有守軍與雙 TC 的基本食物收入，再存 1000 食＋800 金。約 65–85 村開始檢查是否能跟帝，是方便練習的範圍；對方已準備帝王、自己有資源就提前點，不等補滿村數。需要搶時機可以短停一座 TC，之後恢復。

二木優先；輪軸在守穩後補。二農配合後續撒田，手推車不要卡住已接近的點帝與守軍費用。弩砲要打移動目標，學院＋彈道有價值；但只有少量輔助、正缺點帝資源時，不要同時點滿所有科技。

已有城堡、約 8–10 弩砲且要繼續補，才考慮銀冠；少量弩砲先把資源留給跟帝。到帝有拆堡需求先出第一台巨投，不讓銀冠、徵兵占住城堡生產。主力仍是步兵就接軍團兵、三級步防與近攻；馬多補戟兵，弩砲成主力才接重型弩砲。不要同時購買所有升級。

有餘裕可補一隻百夫長跟步兵，但它不能代替巨投或主力升級。反推站穩再增加 TC、恢復完整經濟。

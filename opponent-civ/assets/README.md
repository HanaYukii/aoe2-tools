# 介面圖示

主圖示採用第 04 款等距市鎮中心。原圖由 OpenAI image_gen 生成，非遊戲擷取素材。

- town-center：程式、視窗及頁首識別
- map：對局 RP
- hourglass：前期流程
- combat：中期速查及壓堡防守
- scroll：流程庫
- economy：經濟速查
- ram：羅馬推進速查
- sheep：開局調整入口

PNG 保留透明背景；各尺寸為原圖縮放輸出。app.ico 包含 16–256 px，Windows 打包與 runtime PNG 均內建於執行檔，不依賴外部資料夾或 Pillow。

## 文明徽章

`civilizations/` 內建主遊戲 56 文明的 24、32、64、128 px 透明 PNG；`catalog.json` 以遊戲內部英文名稱的小寫作鍵。對局情報、文明分頁、流程庫文明選單與專屬速查頁共用同一組圖示；未知文明使用通用地圖圖示。

由內建 image_gen 生成，材質以第 02 款羅馬軍盾為參考；歷史器物與文化紋樣為設計靈感，並非官方文明徽章或歷史國徽。高解析原圖與提示詞保留在 AoE 研究區的設計素材庫，程式執行不依賴該資料夾。
